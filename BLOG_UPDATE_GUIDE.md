# Інструкція: Як додати нову статтю на сайт

## ВАЖЛИВЕ ПРАВИЛО про дублювання в розділі "Блог"

**⚠️ КРИТИЧНО ВАЖЛИВО:** Всі статті, які публікуються в спеціалізованих розділах (Теплові насоси, Енергоефективність, Бізнес), **ОБОВ'ЯЗКОВО** мають також додаватися до розділу "Блог" (`/blog/index.html`).

### Розділи, що підпадають під це правило:
1. **Теплові насоси** (`/heat-pumps/index.html`)
2. **Енергоефективність** (`/efficiency/index.html`)
3. **Бізнес** (`/business/index.html`)

---

## Покрокова інструкція додавання нової статті

### Крок 1: Створіть окрему сторінку статті

Створіть нову директорію та файл:
```
/blog/назва-статті/index.html
```

**Приклад:** `/blog/programming/index.html`

Структура файлу статті має містити:
- HTML структуру з header та navigation
- Заголовок статті `<h2>`
- Дату публікації з класом `article-date`
- Повний текст статті в `<div class="article-content">`
- Footer

### Крок 2: Визначте категорію статті

Визначте, до якого спеціалізованого розділу належить стаття:
- **Теплові насоси** - технічні статті про теплові насоси, їх роботу, переваги
- **Енергоефективність** - статті про енергозбереження, геотермальні системи, вентиляцію
- **Бізнес** - статті про бізнес-процеси, ціноутворення, команди, стратегію

### Крок 3: Додайте картку статті до спеціалізованого розділу

Відкрийте відповідний файл (`/heat-pumps/index.html`, `/efficiency/index.html` або `/business/index.html`) та додайте картку:

```html
<article class="article">
  <h3>Назва вашої статті</h3>
  <p>Короткий опис статті (1-2 речення)</p>
  <span class="article-date">січень 2026</span>
  <a href="/blog/url-статті/" class="read-more-btn" style="text-decoration: none;">Докладніше</a>
</article>
```

**Розташування:** Додавайте нові статті на початок списку (після `<div class="articles">`).

### Крок 4: ОБОВ'ЯЗКОВО додайте картку до розділу "Блог"

Відкрийте `/blog/index.html` та додайте ТУ САМУ картку статті:

```html
<article class="article">
  <h3>Назва вашої статті</h3>
  <p>Короткий опис статті (1-2 речення)</p>
  <span class="article-date">січень 2026</span>
  <a href="/blog/url-статті/" class="read-more-btn" style="text-decoration: none;">Докладніше</a>
</article>
```

**⚠️ КРИТИЧНО:** Розташовуйте статтю на **ПЕРШОМУ МІСЦІ** в списку (після `<div class="articles" id="articlesContainer">`).

### Крок 5: Оновіть метрики

Після додавання статті оновіть лічильники у файлах:

1. **У відповідному розділі** (`/blog/index.html`, `/heat-pumps/index.html`, `/efficiency/index.html`, `/business/index.html`)

Знайдіть функцію `initializeStats()` і оновіть відповідні числа:

```javascript
function initializeStats() {
  const blogCount = 25;        // +1 до загальної кількості статей у блозі
  const businessCount = 3;     // +1 якщо додали в бізнес
  const heatPumpsCount = 13;   // +1 якщо додали в теплові насоси
  const energyCount = 3;       // +1 якщо додали в енергоефективність

  const expertTotal = blogCount + businessCount + heatPumpsCount + energyCount;
  // ...
}
```

2. **У всіх окремих статтях** (якщо вони містять метрики в header)

Використовуйте скрипт для масового оновлення:

```python
# Створіть файл fix_metrics.py з кодом для оновлення всіх файлів
python3 fix_metrics.py
```

## Приклад повного процесу

### Додаємо статтю "Роль програмування в сучасних теплових насосах"

#### 1. Створюємо файл статті:
```
/blog/programming/index.html
```

#### 2. Додаємо картку до розділу "Теплові насоси":

Відкриваємо `/heat-pumps/index.html` та додаємо:

```html
<article class="article">
  <h3>Роль програмування в сучасних теплових насосах</h3>
  <p>Від обладнання до керованої енергосистеми будинку. Як програмування визначає ефективність теплових насосів</p>
  <span class="article-date">січень 2026</span>
  <a href="/blog/programming/" class="read-more-btn" style="text-decoration: none;">Докладніше</a>
</article>
```

#### 3. ОБОВ'ЯЗКОВО додаємо картку до розділу "Блог":

Відкриваємо `/blog/index.html` та додаємо **НА ПЕРШЕ МІСЦЕ**:

```html
<article class="article">
  <h3>Роль програмування в сучасних теплових насосах</h3>
  <p>Від обладнання до керованої енергосистеми будинку. Як програмування визначає ефективність теплових насосів</p>
  <span class="article-date">січень 2026</span>
  <a href="/blog/programming/" class="read-more-btn" style="text-decoration: none;">Докладніше</a>
</article>
```

#### 4. Оновлюємо метрики:

```javascript
const blogCount = 25;        // було 24, стало 25
const heatPumpsCount = 13;   // було 12, стало 13
```
