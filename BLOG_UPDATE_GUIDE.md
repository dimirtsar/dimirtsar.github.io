# Інструкція: Як додати нову статтю в блог

## Автоматичне відображення на головній сторінці

При додаванні нової статті в розділ "Блог", вона автоматично може з'явитись на головній сторінці в блоці **"Блог - нове"**.

## Кроки для додавання нової статті

### 1. Створіть HTML файл статті

Створіть новий файл в кореневій директорії проєкту з назвою:
```
blog-article-[slug].html
```

Наприклад: `blog-article-my-new-article.html`

### 2. Додайте статтю в blog.html

Відкрийте файл `blog.html` і додайте нову статтю в секцію `<div class="articles" id="articlesContainer">`:

```html
<article class="article">
  <h3>Заголовок вашої статті</h3>
  <p>Короткий опис статті</p>
  <span class="article-date">Місяць Рік</span>
  <a href="blog-article-[slug].html" class="read-more-btn" style="text-decoration: none;">Докладніше</a>
</article>
```

**ВАЖЛИВО:** Додавайте нові статті **НА ПОЧАТОК** списку (після `<div class="articles" id="articlesContainer">`), щоб вони були першими в списку.

### 3. Оновіть головну сторінку (index.html)

Відкрийте файл `index.html` і знайдіть секцію з коментарем:
```javascript
// Latest blog articles - ОНОВЛЮЙТЕ ЦЕЙ МАСИВ ПРИ ДОДАВАННІ НОВИХ СТАТЕЙ У blog.html
const latestBlogArticles = [
```

Додайте вашу нову статтю **НА ПОЧАТОК** масиву (перший елемент):

```javascript
const latestBlogArticles = [
  {
    title: 'Заголовок вашої нової статті',
    description: 'Короткий опис вашої статті',
    date: 'Місяць Рік',
    url: 'blog-article-[slug].html',
    tag: 'Бізнес' // або 'Менеджмент', 'Технології' тощо
  },
  // ... інші статті
];
```

### 4. Підтримуйте актуальність

На головній сторінці відображаються останні **3 статті** з блогу. Коли ви додаєте нову статтю:

1. Додайте її на початок масиву `latestBlogArticles`
2. Якщо в масиві вже є 3 статті, видаліть останню (найстарішу)
3. Таким чином завжди будуть відображатися 3 найновіші статті

## Приклад повного процесу

1. Створюємо файл: `blog-article-new-topic.html`

2. Додаємо в `blog.html`:
```html
<article class="article">
  <h3>Нова тема для обговорення</h3>
  <p>Цікавий опис нової теми</p>
  <span class="article-date">Лютий 2026</span>
  <a href="blog-article-new-topic.html" class="read-more-btn" style="text-decoration: none;">Докладніше</a>
</article>
```

3. Оновлюємо масив в `index.html`:
```javascript
const latestBlogArticles = [
  {
    title: 'Нова тема для обговорення',
    description: 'Цікавий опис нової теми',
    date: 'Лютий 2026',
    url: 'blog-article-new-topic.html',
    tag: 'Бізнес'
  },
  {
    title: 'Ринкові ціни в інженерії...',
    // ... (попередня перша стаття)
  },
  {
    title: 'Чому одні продукти коштують дорожче...',
    // ... (попередня друга стаття)
  }
  // Видаляємо третю стару статтю
];
```

## Категорії тегів

Рекомендовані категорії для тегу `tag`:
- **Бізнес** - статті про бізнес-процеси, стратегію, розвиток
- **Менеджмент** - статті про управління, лідерство, команди
- **Технології** - технічні статті, інновації
- **Енергетика** - статті про теплові насоси, енергоефективність
- **Інновації** - нові рішення, підходи

## Важливо

- Завжди додавайте нові статті **на початок** списків
- Підтримуйте не більше 3 статей на головній сторінці
- Формат дати: `Місяць Рік` (наприклад: `Січень 2026`)
- URL статті має співпадати з назвою файлу
