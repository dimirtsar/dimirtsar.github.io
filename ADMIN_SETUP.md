# Налаштування адмін-панелі блогу

## Що створено

Система управління статтями блогу складається з:

1. **База даних Supabase** - таблиця `blog_articles` для зберігання статей
2. **Адмін-панель** - `/admin.html` для управління статтями
3. **Динамічний блог** - `/blog.html` автоматично завантажує статті з БД

## Як створити адмін-акаунт

### Варіант 1: Через Supabase Dashboard

1. Відкрийте [Supabase Dashboard](https://0ec90b57d6e95fcbda19832f.supabase.co)
2. Перейдіть в розділ "Authentication" → "Users"
3. Натисніть "Add user" → "Create new user"
4. Введіть:
   - Email: ваш email
   - Password: надійний пароль
   - Auto Confirm User: увімкніть (щоб не потрібно було підтверджувати email)
5. Натисніть "Create user"

## Як використовувати

### Вхід в адмін-панель

1. Відкрийте `/admin.html` у браузері
2. Введіть email та пароль
3. Натисніть "Увійти"

### Створення нової статті

1. Натисніть "Додати нову статтю"
2. Заповніть поля:
   - **Назва статті** - заголовок статті
   - **URL (slug)** - унікальний ідентифікатор для URL (наприклад, `nova-stattya`)
   - **Категорія** - виберіть категорію
   - **Короткий опис** - короткий текст для попереднього перегляду
   - **Повний текст (HTML)** - повний вміст статті в HTML форматі
   - **URL зображення** - шлях до зображення (наприклад, `images/photo.jpg`)
   - **Опублікувати статтю** - позначте, щоб статтю було видно на сайті
3. Натисніть "Зберегти"

### Редагування статті

1. Знайдіть статтю в списку
2. Натисніть "Редагувати"
3. Внесіть зміни
4. Натисніть "Зберегти"

### Видалення статті

1. Знайдіть статтю в списку
2. Натисніть "Видалити"
3. Підтвердіть видалення

## Структура бази даних

Таблиця `blog_articles` містить:

- `id` - унікальний ідентифікатор
- `title` - назва статті
- `slug` - URL-friendly ідентифікатор
- `excerpt` - короткий опис
- `content` - повний текст (HTML)
- `category` - категорія
- `image_url` - URL зображення
- `published` - статус публікації (true/false)
- `author` - автор (за замовчуванням "Dmytro Tsarenko")
- `created_at` - дата створення
- `updated_at` - дата оновлення

## Безпека

- Усі операції запису (створення, оновлення, видалення) доступні тільки авторизованим користувачам
- Публічні користувачі можуть бачити лише опубліковані статті (`published = true`)
- RLS (Row Level Security) увімкнено для захисту даних

## Категорії статей

Доступні категорії:
- `technology` - Технології
- `business` - Бізнес
- `heat-pumps` - Теплові насоси
- `energy` - Енергоефективність
- `general` - Загальне

## Підтримка

При виникненні проблем перевірте:
1. Чи правильно введені дані для входу
2. Чи активовано користувача в Supabase Dashboard
3. Консоль браузера (F12) на наявність помилок
